# Community study guide

Start with one chapter and try its small exercise. The **25 October 2026**
edition has 20 pages, seven real Studio screenshots and 13 lesson invitations.
It was prepared with an AI agent for the community study group and checked
against Studio source `e95d81f`.

## Read or download

- **In Studio:** choose **Community guide** on Home, or **About → Getting started → Read guide**.
  The bundled guide opens in another tab and works without a Discord account.
- **On GitHub:** [read the PDF](../web/community-guide/guide.pdf).
- **Offline:** [download the guide ZIP](../web/community-guide/community-guide-2026-10-25.zip?raw=1),
  extract it, then open `index.html`. It includes the PDF, HTML, screenshots,
  agent template and lesson invitations.
- **For an assistant:** [download directors.md](../web/community-guide/directors.md).
  Replace its placeholders and tell your assistant to read it; the filename
  alone does not make agents discover it automatically.

The same [HTML reading copy](../web/community-guide/index.html) and
[copyable lesson invitations](../web/community-guide/discord-posts.html) are
tracked here. GitHub shows HTML source; use Studio or the extracted ZIP to
read these as pages.

## Follow along

| Topic | PDF pages | What to try |
|---|---|---|
| Install Studio | 2–4 | Choose Windows, Linux x64/ARM64 or macOS Apple silicon/Intel, then complete first setup. |
| Make a YuE2 song | 5–6 | Keep a reproducible recipe and compare one change at a time. |
| Pictures and MOSS | 7–10 | Start with Standard, then compare Spectrum, Turbo/DMD, Kromoss or HiRes deliberately. |
| YuE2 training | 11–12 | Choose the compatible training path and evaluate a held-out example. |
| Video and H3 | 13–14 | Keep component files on auto, check reference settings and render one short pilot. |
| Music videos, films and series | 15–17 | Plan continuity, choose takes, cut and review the actual export. |
| Agents and the study group | 18–20 | Use directors.md, connect through MCP and share a focused experiment. |

Studio installation and model readiness are separate checks. The macOS
preview is ad-hoc signed without Apple notarization; see the
[current Mac installation notes](macOS-install.md). Native YuE2 GGUF automatic
runtime setup currently targets Windows x64; other platforms need a supported
engine route. See [Linux installation](LINUX_INSTALL.md) for its tested scope.

The H3 v1.1 speed result comes from one matched comparison, not every machine
or scene. MOSS is the experimental text-to-image route; Qwen remains the shipped
reference-image/editing route. The optional Uncensored preset is explicit, not
the default, and the guide uses a neutral, fully clothed example.

For settings newer than the dated guide, use the current
[H3 recipe notes](H3_REF_TURBO.md), [MOSS options](MOSS_IMAGE.md),
[Spectrum setup](MOSS_SPECTRUM_SETUP.md) and [Kromoss/HiRes notes](MOSS_KROMOSS_HIRES.md).

The [study-group post](https://discord.com/channels/1404172225124503694/1560517576633622548/1563789381368684546)
has the same edition and screenshot previews. Share your platform, recipe,
actual timing and one thing that worked or drifted. Keep private keys,
recordings and personal paths out of shared screenshots.
