Start with Music only

YuE2 music without ComfyUI or Python.

Choose Q4 or optional Q8

Q4_0 is the smaller default: about 2.93 GB of model files. Q8_0 is higher precision: about 4.53 GB. Both share an F16 VAE and four sidecars. Runtime downloads are separate: about 833 MB for NVIDIA, 58 MB for Vulkan or 24 MB for CPU. Install explicitly in Models; source and integrity checks travel with the manifest.

49.4 seconds of audio in 22.0 seconds

One short-song test on an RTX 4070 Ti SUPER with 16 GB VRAM, CoT full and 32 synthesis steps. This is one measured run, not a promised speed or long-song quality comparison.

Controls that match this engine

CoT full, melody or off; 32 synthesis steps by default, with 16 experimental. Import ABC notation and plan bars, BPM and nominal length in Music or through MCP. Planning uses no GPU; changing a score generates a new take, not seamless extension. Choose installed Q4/Q8 weights per take in Music or through MCP; no silent substitution. Nonempty lyrics required; reference audio and instrumental support depend on the route. See the guide for this native engine's current limits.

Sampled whole-GPU peak: 6,589 MiB, baseline 3,129 MiB. Other applications are included: this is not a process-memory peak or certification for 6 GB or 8 GB cards. YuE2 weights use CC BY-NC 4.0. Studio's output label follows the authors' statement that individuals may sell output and companies need a commercial licence; review the linked licence details before publishing. Q8 has not yet been GPU-benchmarked or listening-tested in Studio; higher precision is not a guaranteed quality upgrade. Read the benchmark and licence limits.

The song, the words, the singing, every frame, the cover — all of it generated on a single consumer graphics card, in this program. No cloud service was called, no credits were spent, and nothing was uploaded.

Each render on this page went through the engine door, which wrote the graph, the prompt verbatim, the seed, the model files and the hash of every reference before the card spent a second on it. That is what makes “100% AI-generated” a checkable statement here rather than a slogan.

The program itself

Getting it running

Install

For native music, start with Node.js 20+ and Studio. No ComfyUI setup, Python environment or unrelated model download.

On Windows: download AIPLAY Studio Setup.exe and run it. It installs Studio, plus a private Node.js 20+ when this PC has none, with no admin prompt. Windows may say “Windows protected your PC” because the installer is not signed yet: click More info, then Run anyway.

Same public GitHub, two local launch modes. YuE2 music-only is part of AIPLAY Studio, not a separate repository. You download the app, then only the models you choose.

When Setup asks which build, choose Senzu's.

Music only

Native YuE2 GGUF songs on NVIDIA, AMD, Intel or CPU. No ComfyUI, Python or unrelated models. Start small; speed depends on your hardware.

Full Studio

The wider music, DAW, image, vector, video, VFX and 3D suite. Uses ComfyUI and Python for applicable tools. The launcher can find an existing ComfyUI or install a private one; optional packs have separate requirements.

Optional hosted services

Full Studio can use hosted MiniMax music with your fal.ai key. The separate Use Comfy API launch mode offers hosted pictures, clips, sound and 3D with your Comfy key; it has no Music or Production screen. Inputs go to the provider, and its usage charges apply.

Source code (for developers):

git clone https://github.com/Senzube4n/AIPLAY-Studio.git
cd AIPLAY-Studio
npm ci --omit=dev
npm run start:music

Or download and extract the source ZIP (for developers; it needs Node.js installed by hand). Either way, start AIPLAY Studio.exe and choose Music only. In Models, explicitly install YuE2 GGUF Q4 or Q8 and its native runtime, then enter a style and lyrics in Music and press Create. The installer shows the download total and notices; unavailable or unverified packages must not appear ready.
