Experimental native music

A smaller starting point. A measured short-song result.

Choose Q4 or optional Q8

Q4_0 is the smaller default: about 2.93 GB of model files. Q8_0 is higher precision: about 4.53 GB. Both share an F16 VAE and four sidecars. The native runtime is a separate 833 MB download. Install explicitly in Models; source and integrity checks travel with the manifest.

49.4 seconds of audio in 22.0 seconds

One short-song test on an RTX 4070 Ti SUPER with 16 GB VRAM, CoT full and 32 synthesis steps. This is one measured run, not a promised speed or long-song quality comparison.

Controls that match this engine

CoT full, melody or off; 32 synthesis steps by default, with 16 experimental. Import ABC notation and plan bars, BPM and nominal length in Music or through MCP. Planning uses no GPU; changing a score generates a new take, not seamless extension. Choose installed Q4/Q8 weights per take in Music or through MCP; no silent substitution. Nonempty lyrics required. No guaranteed duration, instrumental mode, audio references, mix-cache reuse or native score export.

Sampled whole-GPU peak: 6,589 MiB, baseline 3,129 MiB. Other applications are included: this is not a process-memory peak or certification for 6 GB or 8 GB cards. YuE2 weights use CC BY-NC 4.0; Studio conservatively labels output noncommercial / not for sale, without claiming the weight licence automatically governs every song. Q8 has not yet been GPU-benchmarked or listening-tested in Studio; higher precision is not a guaranteed quality upgrade. Read the benchmark and licence limits.

A song with a score

The second music engine writes a two-voice lead sheet with chords before it sings. Read it, edit it, render again — print it as sheet music, open it in the DAW, or take it out as MIDI. Ask for a key, a tempo and a meter and it plans in them; hum a line or hand it a whole song to cover; extend a take or replace a section of it.

It can also carry on from a recording you own, not just from its own output: the audio becomes the codes the model speaks and the render continues from them. Measured, a continuation holds 0.9947 against its source where a fresh render on the same prompt holds −0.003. The same codes make your library searchable by how a song sounds — asked for one track, it put that recording first at 0.56 with everything else below 0.11.

Making something with friends

Swap key cards, read twelve words aloud to each other, and a project travels as one sealed file addressed to one person. You can also lend each other a graphics card: an order asking a friend to render one scene carries four words — the scene, the seed, the steps and the engine — and no graph, no tool name, no model and no path. On their machine it becomes a plan that a person approves, and the finished take comes back to quarantine for you to adopt or throw away, carrying their model and their licence.

There is no server anywhere in it and nothing opens a connection. Six attackers were pointed at the receive path, each holding a key the victim trusts, and every finding was handed to a skeptic told to refute it.

Why bother running it yourself

The three promises this makes

Nothing leaves the machine

No account, no upload, no per-render charge, no terms that change next quarter. Your unfinished work stays unfinished in private.

It ships no model weights

Every model is downloaded from its own publisher, and the Models screen shows you the licence and the territory it applies to before anything is fetched. Some are free for commercial use and some are not. The program tells you which, and refuses to guess on your behalf.

Every render is recorded

One door to the graphics card, and it writes the graph, the prompts verbatim, the seed, the step count, the size, every model file and the hash of every reference before the card spends. Failed renders are recorded too. You can always answer “how was this made?”.

It also publishes its own negative results. Where a feature is weaker than it sounds, the documentation says so and shows the measurement — including the ones that did not go our way.

The program itself

Getting it running

Install

For native music, start with Node.js 20+ and Studio. No ComfyUI setup, Python environment or unrelated model download.

On Windows: download AIPLAY Studio Setup.exe and run it. It installs Studio, plus a private Node.js 20+ when this PC has none, with no admin prompt. Windows may say “Windows protected your PC” because the installer is not signed yet: click More info, then Run anyway.

Same public GitHub, two launch modes. YuE2 music-only is part of AIPLAY Studio, not a separate repository. You download the app, then only the models you choose.

Source code (for developers):

git clone https://github.com/Senzube4n/AIPLAY-Studio.git
cd AIPLAY-Studio
npm ci --omit=dev
npm run start:music

Or download and extract the source ZIP (for developers; it needs Node.js installed by hand). Either way, start AIPLAY Studio.exe and choose Music only. In Models, explicitly install YuE2 GGUF Q4 or Q8 and its native runtime, then enter a style and lyrics in Music and press Create. The installer shows the download total and notices; unavailable or unverified packages must not appear ready.
